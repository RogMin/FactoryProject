# Робот-шнекоход для преодоления полосы препятствий

## 📦 Компоненты проекта

- `x1` ESP32
- `x2` Холдер для батареек
- `x2` DC-мотора с редуктором  
- `x2` Шнеки Архимеда (распечатанные на 3 принтере)  
- `x1` Светодиод  
- `x3` Саморезы (в качестве иголки) для прокалывания шариков   
- `x2` Детали корпуса
- `x1` Плата
- `x1` Силовой ключ N-Channel v3
- `x1` Драйвер для двух моторов TB6612
---

## ⚙️ Описание конструкции

Робот движется за счёт **двух винтов Архимеда**, которые вращаются в **разные стороны**. Такая конструкция создаёт устойчивое поступательное движение и обеспечивает **повышенную проходимость** на рыхлых и вязких покрытиях
Корпус робота состоит из **двух основных деталей**, которые соединяются с друг-другом:

 *Первая часть* — здесь снизу закреплены моторы, плата

 *Вторая часть* — на нём закреплены подшипники снизу, оба держателя для батареек

На передней части корпуса размещены **3 острых самореза**, направленных вперёд — они нужны для **прокалывания воздушных шаров** и светодиод, необходимый для прохождение трассы.

Робот управляяется через Wi-Fi с помощью телефона.
